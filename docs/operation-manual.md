# 制造品质管理系统 — 操作说明书

> 适用版本：v2.x | 最后更新：2026-08-04

## 一、系统概述

制造品质管理系统含**样品管理**、**治具管理**与**全局工作台**三大子系统，通过统一门户入口（portal.html）进入，三方扫码驱动状态流转，全程留痕。

### 1.1 样品管理子系统

覆盖样品从「建样→制作确认→发行→保管→复检」全生命周期。

| 角色 | 代码 | 职责 | 典型账号 |
|---|---|---|---|---|
| 研发 | RD | 建样、打印贴样、扫码确认制作完成 | rd01 |
| 生技 | ME | 同保管：扫码接收、登记储位、申请退回 | me01 |
| 品保 | QA | 扫码确认发行、设置复检周期、复检 | qa01 |
| 保管 | CUSTODY | 扫码接收、登记储位、日常保管 | mfg01 / fqc01 |
| 管理员 | ADMIN | 用户管理、全局查看 | admin |

> 生技部(ME)属于保管单位，不可建样和确认制作。

**状态机**：`新建·待制作确认 → 制作完成 → 已发行 → 保管中 → 退回审核中 → 已作废`

### 1.2 治具管理子系统

覆盖治具从「申请→制作→验证移交→领用→维修/改善→报废」全生命周期。

| 角色 | 治具职责 |
|---|---|
| 研发(RD) | 制作治具、维修治具（RD维修中）|
| 生技(ME) | 保养治具、ME侧验证/确认维修、领用 |
| 品保(QA) | 验证移交、领用（同 CUSTODY）|
| 各部门保管(CUSTODY) | 验证移交、领用 |
| 管理员(ADMIN) | 报废治具、全局查看 |

**状态机**：`已申请→已接收→待验证→已移交→领用中→(维修/改善)→已报废`

> 验证为**单人验证**：制作完成后，由**申请部门人员**扫码验证即可移交，无需研发二次确认。

### 1.3 全局工作台子系统

跨部门汇总样品 + 治具的活跃项目，按部门展示积压情况，帮助各部门掌握整体进度。

| 功能 | 说明 |
|---|---|
| 统计卡片 | 总计 + 各部门卡片，互斥三档积压（≤3 天 / 3~7 天 / 7 天以上） |
| 卡片交互 | 单击部门卡筛选该部门数据、再次单击取消；单击总计卡清除筛选 |
| 统一列表 | 编号/名称/类型/阶段/负责部门/申请部门/停留时长/积压状态，支持类型与积压等级筛选 |
| 阈值设置 | **仅管理员(ADMIN)**：工作台右上「阈值设置」可调整 3 天 / 7 天边界，保存后全局生效 |

> 普通用户无需配置，按管理员设定的阈值查看即可；标签文字会随阈值自动变化（如「≤5 天 / 5~10 天 / >10 天」）。

## 四、建样（研发）

### 4.1 新建样品

1. 点击左侧菜单「新建样品+打印码」
2. 填写**基础信息**（左栏）：
   - **样品名称** *（必填）* — 如「1225震动样」
   - **机型** — 如「1225」「X200」
   - **站别** — 下拉选择（马达组/扇叶组/成品组/调机样）
   - **规格/型号** — 如容量、尺寸等
   - **备注** — 自由文本
3. 限度样品信息（右栏，选填）：
   - **样品类型**：OK样品 / NG样品
   - **限度项目**：下拉选择（如「成品震动」「外观」等 26 项）
   - **来源**：客供 / 元山 / 塔岗
   - **版次**：首发自动 `01`，重新发行自动 +1（如 `02`→`03`，最高99），也可手动输入（如 `03`）
   - **标准范围**：如「震动≤0.5mm」「噪音≤30dB」— 这是限度判定标准，不同于标示卡上的「测试数据」（实测数值）
   - > 注：标示卡上的「测试数据/样品数值」在品保发行或复检时填写；「制作签署人」由系统自动填入当前登录用户
4. 点击「创建样品并生成条码」
5. 系统自动生成编号（格式 `SM-XXXXXX`），弹出**标签打印**页面（左半 QR码+基本信息，右半空白标示卡区）
6. 打印标签，**贴于样品实物上**

### 4.2 补打标签

如标签遗失或打印失败，可到「样品列表」→ 找到对应样品 → 点击「打印」：

- **打印**：弹出标签打印页（含 QR 码 + 编号 + 名称/机型/站别/规格）
- **下载 QR**：下载高分辨率 PNG 二维码，供条码打印软件导入

### 4.3 标签尺寸设置

标签打印页和标示卡打印页顶部提供**尺寸选择器**：

| 尺寸 | 标签 | 标示卡 |
|------|------|--------|
| 小号 | 37×18mm | 21×12mm |
| 中标 | 52×25mm（默认） | 29×17mm |
| 大号 | 74×35mm | 41×24mm |
| 自定义 | 30~150mm 可调 | 自动等比缩放 |

- 标签打印页：尺寸选择器**可修改**，选择后标签内容按比例缩放
- 标示卡打印页：顶部显示只读尺寸标签（跟随标签尺寸自动适配）
- 切换尺寸后，已打开页面的布局实时更新

## 五、扫码台（三方共用）

扫码台是系统核心入口，三方通过扫描样品二维码驱动状态流转。进入「扫码台」页面后：

### 5.1 扫码方式

| 方式 | 适用场景 |
|---|---|
| **扫码枪**（推荐） | 桌面端批量作业，对准二维码扫描即可自动填充 |
| **手动输入** | 无扫码枪时，输入样品编号（格式 `SM-XXXXXX`，6 位数字）后回车。格式不合法将提示错误。 |
| **摄像头扫码** | 手机端（仅 HTTPS 可用），点击「开启摄像头」对准二维码。HTTP 下折叠区会显示不可用提示。 |

**连续扫码**：勾选「连续扫码」后，每次操作完自动清空输入框聚焦，适合扫码枪批量作业。

### 5.2 研发确认制作（RD）

> 流程：新建·待制作确认 → 制作完成

1. 将标签贴于制作完成的样品上
2. 在扫码台扫描该样品二维码
3. 系统显示样品信息，确认无误后：
   - **上传制作照片** *（必填）* — 点击「选择文件」
   - 可选填写**备注**
4. 点击「确认制作完成（研发）」
5. 状态更新为「制作完成」，系统记录操作日志

### 5.3 品保确认发行（QA）

> 流程：制作完成 → 已发行

品保发行使用**分步向导**，分三步完成：

**Step 1 — 设置复检周期**

1. 扫描「制作完成」状态的样品二维码
2. 系统显示样品信息，设置**复检周期（天）** *（必填）*
3. 实时预览下次复检日期
4. 点击「下一步：填写标示卡」

**Step 2 — 标示卡审查**

1. 全部标示卡字段平铺展开（无折叠），逐字段显示状态标记：
   - `✓ RD已填`（绿色）— 研发已填写
   - `✗ 必填`（红色）— 必填字段未填写
2. 填写必填字段：
   - **样品类型** *（必填）* — OK样品 / NG样品
   - **限度项目** *（必填）* — 26 项下拉选择
3. 可选字段自动带入研发建样时填写的数据：来源、测试数据（有效期自动等于复检日，品保发行/复检时由系统自动填充）。**版次**：发行时自动设为 `01`，重新发行时自动 +1（如当前 `01` → 默认填入 `02`，可手动调整，最高 `99`）。
4. 品保确认人自动签署为当前登录用户
5. 点击「下一步：确认发行」（类型+项目未填则无法进入下一步）

**Step 3 — 确认 & 发行**

1. 展示发行摘要：复检周期、下次复检日期、类型、项目
2. 核对无误后点击「确认正式发行（品保）」
3. 系统记录操作日志，自动计算下次复检日期
4. 标示卡自动弹出打印（非连续模式）/ 加入打印队列（连续模式）

### 5.4 品保复检（QA）

> 流程：已发行（已到期）→ 更新复检日期

当样品到了复检日期后，品保需对实物进行复检：

1. 扫描到期样品二维码
2. 系统显示复检操作界面：
   - **上传复检照片** *（必填）*
   - 可选填写**备注**
   - 复检周期默认沿用上次周期，也可修改
3. **标示卡更新**（选填）— 展开「标示卡更新」折叠区，可修改版次/测试数据，不填则保留原值。有效期自动等于复检日，由系统自动同步。
4. 点击「确认复检完成（品保）」
5. 下次复检日期自动顺延。如填写了标示卡字段，日志会注明「标示卡已更新」

### 5.5 保管接收（CUSTODY）

> 流程：已发行 → 保管中

1. 收到品保发行的样品后，扫描其二维码
2. 填写**保管储位** *（必填）* — 如「A区-3架-2层」
3. 点击「确认接收保管（XX部）」
4. 状态更新为「保管中」，记录储位和保管部门

### 5.6 保管申请退回（CUSTODY）

> 流程：保管中 → 退回审核中

1. 扫描「保管中」状态的样品二维码
2. 点击「申请退回」按钮
3. 填写**退回原因** *（必填）* — 如「样品外观损坏，需重新制作」
4. 点击「提交退回申请」
5. 状态更新为「退回审核中」，等待品保审核

### 5.7 品保审核退回（QA 4 分支）

> 流程：退回审核中 → 多分支

扫描「退回审核中」状态的样品二维码，系统显示 4 个操作按钮：

**分支 1 — 重新发行**

1. 点击「重新发行」
2. 进入品保发行分步向导：设置复检周期 → 修改标示卡信息（版次自动 +1，可手动调整）→ 确认发行
3. 状态更新为「已发行」，按正常流程重新分发

**分支 2 — 退回研发重做**

1. 点击「退回研发重做」
2. 下拉选择指派的研发人员
3. 可选填写作废原因
4. 样品保持「退回审核中」状态，被指派的研发在首页看到待办
5. 研发执行「创建替代品」（见 5.8）后，原样品自动变为「已作废」

**分支 3 — 直接作废**

1. 点击「直接作废」
2. 填写**作废原因** *（必填）*
3. 确认后状态更新为「已作废」

**分支 4 — 拒绝退回**

1. 点击「拒绝退回」
2. 填写**拒绝理由** *（必填）* — 如「样品完好，无需退回」
3. 状态恢复为「保管中」

### 5.8 研发创建替代品（RD）

> 流程：退回审核中（已被指派）→ 新建替代样品

1. 被指派的研发扫描「退回审核中」样品二维码
2. 点击「创建替代品」
3. 系统自动复制原样品信息（名称、规格、机型、站别、标示卡等）
4. 生成新的样品编号，新样品状态为「新建·待制作确认」
5. 原样品记录被替代关系，新样品按正常流程制作→发行→分发

### 5.9 无权操作

如果扫描的样品状态与当前角色不匹配，系统会提示：

> "你的角色（XXX）无法推进该样品，请确认流程顺序或由对应部门操作。"

常见原因：样品尚未制作完成研发就去确认发行、样品还未发行保管就去接收等。

### 5.7 标示卡打印队列（连续模式）

勾选「连续扫码」时，品保发行后标示卡不清空列表，而是加入打印队列：

1. 每次发行成功，扫码区下方显示 `已积累 N 张标示卡`
2. 全部发行完毕后，点击「打印全部」— 依次弹出标示卡打印页
3. 也可随时「清空」队列
4. 离开页面时如有未打印队列，浏览器会弹出确认提示

> 非连续模式下，发行成功后直接弹出单张标示卡打印页，行为不变。

## 六、样品列表

点击「样品列表」查看所有样品，支持以下筛选：

| 筛选条件 | 说明 |
|---|---|
| 搜索 | 按编号/名称/规格模糊搜索 |
| 状态 | 待制作 / 制作完成 / 已发行 / 保管中 / 退回审核中 / 已作废 |
| 部门 | 按保管部门筛选 |
| 类型 | OK样品 / NG样品 |
| 限度项目 | 26 项下拉 |
| 来源 | 客供 / 元山 / 塔岗 |
| 排序 | 最新优先 / 最早优先 / 编号升/降序 |

**快捷筛选**：待处理 / 逾期 / 近 7 天

### 6.1 样品详情

点击列表中「详情」链接，弹出详情弹窗，最多包含四个 Tab（按实际数据动态显示）：

- **信息**：基础信息（名称/机型/站别/规格/备注）、流转进度（各阶段时间和操作人）、保管信息（部门/储位）、操作日志（最近 2 条，可点击「查看全部 N 条」切换全量视图）
- **标示卡**（仅有限度信息的样品显示此 Tab）：
  - 查看/编辑标示卡字段：样品类型、限度项目、来源、版次、样品数值、制作签署人、确认签署人。有效期自动等于复检日，由系统自动同步。
  - 已发行/保管中/退回审核中/已作废的样品标示卡自动锁定，仅可查看和打印，不可修改
  - 保存标示卡 → 点击「打印标示卡」弹出打印页面
- **全量日志**：当前样品的全部操作记录（有日志数据时显示）
- **大图**：制作照片/复检照片查看（有图片数据时显示）

### 6.2 取消样品

仅「新建·待制作确认」或「制作完成」状态的样品可取消（ADMIN/研发/创建者）：

1. 在列表中点击「取消」
2. 确认弹窗 → 确定后删除样品及关联日志（**不可恢复**）

## 十、数字标示卡（匿名查看）

每个样品生成后可生成一个**匿名数字标示卡**页面，供现场人员在无账号的情况下扫码查看：

- URL 格式：`/card/SM-XXXXXX`（无需登录）
- 页面内容：
  - **基本信息**：样品编号、名称
  - **标示卡信息**：样品类型（OK样品/NG样品 色标）、限度项目、来源、版次、样品数值
  - **有效期**：自动等于复检日，过期则红色标注「已过期」
  - **签署**：制作人、确认人
  - **规格/型号**：机型、站别、规格
  - **最近操作记录**（最近 2 条）
- 适合现场扫码枪/手机在无登录状态下快速查看关键信息

## 十一、完整操作流程图

```
研发建样 ──→ 打印标签（QR+空白标示卡区）──→ 贴于样品
                │
                ▼
        【扫码台：研发确认制作】  上传制作照片
                │  新建·待制作确认 → 制作完成
                ▼
        【扫码台：品保确认发行】  设置复检周期 + 填写标示卡
                │  制作完成 → 已发行   → 自动弹出标示卡打印页
                ▼
        【扫码台：保管接收】      填写储位
                │  已发行 → 保管中
                ▼
            保管中 ──→ 到期 ──→ 【扫码台：品保复检】  上传复检照片 + 标示卡更新（选填）
                ▲                        │
                └────── 周期顺延 ←────────┘
                │
                ▼ (保管申请退回)
        【扫码台：保管申请退回】  填写退回原因
                │  保管中 → 退回审核中
                ▼
        【扫码台：品保审核退回】  QA 4 分支：
                │  ├─ 重新发行 → 已发行（继续分发流程）
                │  ├─ 退回研发重做 → 已作废（研发收到待办 → 创建替代品）
                │  ├─ 直接作废 → 已作废
                │  └─ 拒绝退回 → 保管中（恢复保管）
```

## 十二、帮助指南

系统内置完整的操作帮助指南，方便新用户快速上手：

### 12.1 打开帮助

1. 点击页面**右下角蓝色「?」浮动按钮**

## 十三、治具管理（子系统入口）

治具管理系统通过门户进入（`subsystems/fixtures/frontend/index.html`），与样品系统共享用户体系和 CSS 样式，通过左侧菜单切换功能页面。

### 13.1 治具看板

治具看板展示以下四大区块（按优先级排列）：

1. **统计卡片**（7 张）：待验证、可领用、领用中、维修中、改善中、报废。点击卡片筛选下方待办列表，再次点击取消筛选。**待验证 = 制作完成但尚未验证移交的治具**。

2. **逾期未归还预警**：领用超过 30 天仍无归还动作的条目，红色动画标注。

3. **待保养预警**：保养周期内未执行保养的条目，含「上次保养日期」「保养周期」「已逾期天数」。

4. **我的待办**：按当前登录角色自动列出需要你操作的治具（如 ME 看到待验证/待保养，RD 看到待制作/待维修等）。

### 13.2 治具清单

治具清单支持以下筛选和功能：

| 功能 | 说明 |
|---|---|
| 搜索 | 按编号/名称模糊搜索 |
| 状态 | 12 种状态下拉筛选 |
| 部门 | 按申请部门筛选 |
| 排序 | 编号升/降序 |
| 每页条数 | 10/20/50/100 自选 |
| 列宽拖拽 | 拖拽表头右侧把手调整列宽 |
| 响应式 | 移动端自动切换标签-值纵向卡片布局 |

所有状态标签有独立颜色（Green/Blue/Amber/Red/Gray），视觉区分。

### 13.3 新建治具（RD/ADMIN）

1. 点击「新建治具」
2. 填写**治具名称**、**规格/型号**、**数量**、**适用机型/站别**
3. 选择**申请部门**
4. 可选：上传设计图纸、采购订单等附件，以及治具照片
5. 点击「提交申请」
6. 系统自动生成编号 `FJ-XXXXXX`（6 位流水号），状态为「已申请」
7. 研发可点击「开始制作」→ 状态变为「已接收」

### 13.4 治具详情弹窗

治具列表/看板中点击详情，弹出详情弹窗（与样品详情弹窗同架构），包含：

- **信息 Tab**：基础信息卡片（编号/名称/规格/数量/机型/申请部门）、文件分组（设计图纸/采购订单/治具照片/保养照片/现场照片）、操作日志（最近 2 条，可点击「查看全部 N 条」）
- **全量日志 Tab**：当前治具的全部操作记录表格（时间/动作/角色部门/备注）
- 底部操作按钮按当前状态和角色动态显示（制作/验证/移交/领用/报修/维修/确认/报废/取消等）

### 13.5 治具扫码台

治具扫码台类似样品扫码台，通过扫描治具二维码驱动状态流转：

| 操作 | 触发状态变化 | 执行角色 |
|---|---|---|
| **确认制作** | REQUESTED/ACCEPTED → VERIFY_PENDING | RD |
| **验证移交** | VERIFY_PENDING → TRANSFERRED | 申请部门人员（ME/QA/CUSTODY） |
| **领用** | TRANSFERRED → IN_USE | ME/QA/CUSTODY |
| **归还** | IN_USE → TRANSFERRED | 领用人 |
| **ME 报修** | IN_USE → REPAIRING_ME | ME |
| **退回 RD 维修** | IN_USE → REPAIRING_RD | ME |
| **RD 维修完成** | REPAIRING_RD → REPAIR_DONE | RD |
| **ME 维修确认** | REPAIRING_ME/REPAIR_DONE → TRANSFERRED | ME |
| **申请改善** | IN_USE → IMPROVING | ME |
| **改善完成报废** | IMPROVING → RETIRED | ADMIN |
| **直接报废** | TRANSFERRED → RETIRED | ADMIN |
| **取消治具** | 仅已申请/已接收状态 | RD/ADMIN |

**验证规则（单人验证）**：
1. 制作完成后，由**申请部门人员**扫码验证即可移交，无需研发二次确认
2. 验证角色限定为 ME/QA/CUSTODY，或与申请部门同部门人员
3. RD 不参与验证（避免制作方自证）；`VERIFY_RD_OK/VERIFY_ORG_OK` 为旧双人验证的历史状态，存量数据兼容

### 13.6 治具保养体系

- 治具移交时设置**保养周期**（天）
- 看板**待保养预警**自动检测逾期保养
- 保养时上传保养照片、填写备注
- 保养记录全量留痕

### 13.7 治具文件管理

- 支持上传 6 类文件：设计图纸(pdf/dwg/dxf/stp)、采购订单(pdf/doc/xls)、治具照片(jpg/png)、保养照片、现场照片、其他(pdf/doc/zip)
- 每类文件有 MIME 白名单校验
- 图片类 ≤10MB，其他 ≤20MB
- 文件按类型分组展示
