# 全局工作台操作说明（使用人员版）

> 适用对象：全体用户（各部门按权限查看积压与个人待办）
> 版本：v2.x | 更新：2026-09-04

---

## 一、工作台是什么

跨子系统的总览驾驶舱：汇总**样品、治具、管制、项目**四个子系统的活跃工作，按部门展示积压情况；并提供「**我的待办**」——五个子系统所有轮到「你」处理的事项，一处聚合、一键直达。

---

## 二、登录与入口

1. 门户登录后点击「**全局工作台**」卡片
2. 左侧菜单：积压总览（默认）/ 我的待办 / 阈值设置(管理员)

---

## 三、积压总览

- **统计卡片**：总计 + 各部门卡片，按停留时长分三档（默认 ≤3 天 / 3~7 天 / >7 天，管理员可调）
- **交互**：单击部门卡筛选该部门数据（再点取消）；点总计卡清除筛选
- **筛选栏**：类型 / 积压等级 / 负责部门 / 申请部门 / 编号名称搜索 / 仅呆滞 / 停留时长范围，多维组合、服务端过滤，「共 N 条」实时计数
- **分页与记忆**：筛选条件与页码写入网址，刷新/分享链接后自动恢复
- 单击任意记录直达对应子系统的详情

---

## 四、我的待办（核心功能）

### 4.1 它是什么

把散在五个子系统里「轮到你处理」的事聚合到一个页面：样品待制作确认、治具待验证、管制单待你会签、项目任务到期……**每天开工先扫一遍，点进去处理完就消失**。

### 4.2 谁会收到什么

> 口径：**行动主体才看待办**——只有当事人和职能口收到提醒，不广播给旁观部门。

| 分组 | 待办规则（谁看到什么） |
|---|---|
| **样品** | 研发=待制作确认/退回重做；品保=待发行/退回审核；保管/生技=待接收（共享池，谁扫谁收）；管理员=全部 |
| **治具** | 研发=待接收/制作中/RD维修；生技=维修/待确认维修/保养到期；申请部门=待验证/可领用/改善中；归还逾期=借用人+借用部门+生技；死锁=管理员 |
| **管制** | 待我流转（提交会签=申请部门；入仓=资材部；报工=生产口；入库/出货=仓口）+ 待我签核（轮到自己部门字位的会签）；管理员=全部会签单 |
| **项目** | 指派给我的未完成任务/子任务（延期带标记） |

### 4.3 怎么用

1. 点左侧「**我的待办**」
2. 按子系统分组列出：编号、名称、待办动作、当前状态；**紧急项**（逾期归还/保养到期/死锁）带紧急标记
3. 单击任意一条 → 直达对应单据详情处理（项目任务直接跳任务页）
4. 处理完回到待办页刷新，该条自动消失；顶部显示各分组数量与总计

> 数据实时生成不落库：处理完即消失；各子系统内部的待办入口（如管制看板待办区）与这里数字一致（同源派生），可互相印证。

---

## 五、阈值设置（仅管理员）

1. 工作台右上「阈值设置」
2. 调整积压分档边界（默认 3 天 / 7 天）
3. 保存后**全局生效**，所有用户的积压标签随之变化（如「≤5 天 / 5~10 天 / >10 天」）

普通用户无需配置。

---

## 六、常见提示

- **我的待办是空的**：正常——说明没有轮到你处理的事项
- **看到了不是本部门的管制单**：待办只投递当事人；若看到本部门申请单的提交会签，说明该单等你部门提交
- **样品「待接收」人人在看**：接收前系统不指定保管部门，谁扫码谁收（收完即从他人待办消失）
- **待办数量与子系统不一致**：刷新页面（数据实时派生）；仍不一致请联系管理员检查
