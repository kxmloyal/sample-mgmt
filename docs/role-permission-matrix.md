# 角色权限对照表（Role-Permission Matrix）

> 数据来源：各子系统 `manifest.json` 的 `stateMachine.transitions` 与 `navigation.roles`（单一事实来源，AGENTS.md §17.3）。
> 更新方式：修改 manifest 后同步本表；本表仅供查阅，不参与运行时校验。
> 最近同步日期：2026-08-07

## 一、角色体系

| 角色 | 全称 | 部门 | 子系统可见性 |
|---|---|---|---|
| **ADMIN** | 管理员 | 系统 | 全部 4 个子系统（含全部管理功能） |
| **RD** | 研发 | 研发部 | 样品 / 治具 / 项目 / 工作台 |
| **QA** | 品保 | 品保文管中心 | 样品 / 治具 / 项目 / 工作台 |
| **ME** | 生技 | 生技部 | 样品 / 治具 / 项目 / 工作台 |
| **CUSTODY** | 保管 | 各部门（制造部 / FQC 等） | 样品 / 治具 / 项目 / 工作台 |
| **PM** | 项目负责人 | — | 仅项目追踪（projects） |

## 二、样品管理（samples，已上线 deployed:true）

**导航权限**：看板 / 列表 / 扫码台 = 全部角色；新建样品、机型列表 = **ADMIN / RD**；操作日志 = **仅 ADMIN**

| 状态转移 | 操作 | 允许角色 |
|---|---|---|
| 新建(待制作) → 制作完成 | 制作完成 | RD |
| 制作完成 → 已发行 | 正式发行 | QA |
| 已发行 → 保管中 | 接收保管 | CUSTODY / ME |
| 保管中 → 退回审核中 | 申请退回 | CUSTODY / ME |
| 退回审核中 → 已发行 | 重新发行 | QA |
| 退回审核中 → 已作废 | 直接作废 | QA |
| 退回审核中 → 保管中 | 拒绝退回 | QA |
| 已发行 ⇄ 已发行 | 复检 | QA |
| 已发行 ⇄ 已发行 | 修正标示卡 | QA |
| 保管中 ⇄ 保管中 | 修改储位 | CUSTODY / ME |
| 退回审核中 ⇄ 退回审核中 | 退回研发重做 | QA |
| 退回审核中 → 已作废 | 创建替代品 | RD |

## 三、治具管理（fixtures）

**导航权限**：看板 / 清单 / 新建申请 / 扫码台 / 操作日志 = 全部角色

| 状态转移 | 操作 | 允许角色 |
|---|---|---|
| 已申请 → 已接收 | RD接收 | RD |
| 已申请 → 已废弃 | 撤销申请 | RD / ADMIN |
| 已接收 → 待验证 | 制作完成 | RD |
| 待验证 → 已移交 | 验证移交 | QA / CUSTODY / ME |
| 已移交 → 领用中 | 领用 | ME / QA / CUSTODY |
| 领用中 → 已移交 | 归还 | ME / QA / CUSTODY |
| 领用中 → ME维修中 | ME自行维修 | ME |
| 领用中 → RD维修中 | 退回RD维修 | ME / QA / CUSTODY |
| ME维修中 → 维修完成 | ME维修完成 | ME |
| RD维修中 → 维修完成 | RD维修完成 | RD |
| 维修完成 → 已移交 | ME确认维修 | ME |
| 领用中 → 改善中 | 申请改善 | ME / QA / CUSTODY |
| 改善中 → 已废弃 | 改善完成 | ME / QA / CUSTODY |
| 已移交 → 已废弃 | **报废** | **仅 ADMIN** |

> 注意：MAKE（制作完成）前置要求「设计图纸 + 实物照片」两类文件齐全，RD 缺文件会被 409 拦截（routes 层校验）。

## 四、项目追踪（projects）

**导航权限**：看板 / 任务看板 / 任务列表 / 项目列表 = ADMIN / PM / RD / QA / CUSTODY / ME；**状态机管理 = 仅 ADMIN**

| 状态转移 | 操作 | 允许角色 |
|---|---|---|
| 未开始 → 进行中 | 开始处理 | PM / ADMIN / 成员 / 负责人 |
| 进行中 → 已完成 | 标记完成 | PM / ADMIN / 成员 / 负责人 |
| 未开始 / 进行中 → 已延期 | 自动延期 | SYSTEM（系统按计划日期自动判定） |

## 五、全局工作台（workbench）

导航 = 全部角色（只读聚合视图，无状态机）。`deployed: false`（未上线）。

## 六、各角色职责速览

| 角色 | 样品 | 治具 | 项目 | 特权 |
|---|---|---|---|---|
| **RD** | 制作 / 建样 / 创建替代品 | 接收 / 制作 / 维修完成 | 任务操作 | 样品新建、机型维护 |
| **QA** | 发行 / 复检 / 退回审核 | 验证移交 / 领用 / 报修 | 任务操作 | — |
| **ME** | 接收保管 / 申请退回 | 验证移交 / 领用 / 维修 / 保养 / 改善 | 任务操作 | — |
| **CUSTODY** | 接收保管 / 申请退回 | 验证移交 / 领用 / 报修 | 任务操作 | — |
| **ADMIN** | 全部 + 操作日志 | 全部 + **报废** | 全部 + 状态机管理 | 用户管理、全局查看 |
| **PM** | — | — | 项目 / 任务管理 | — |
