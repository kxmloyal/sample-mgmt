# 项目追踪系统操作说明（使用人员版）

> 适用对象：项目成员、项目负责人(PM)、管理员
> 版本：v2.x | 更新：2026-09-07（补里程碑/风险/变更/甘特图/关系图谱/模板/状态机管理）

---

## 一、你能做什么

| 角色 | 主要操作 |
|---|---|
| 项目成员 | 查看/处理自己名下任务、评论、上传附件 |
| 项目负责人(PM) | 新建/编辑任务与子任务、项目管理、成员管理 |
| 管理员 ADMIN | 以上全部 + 状态机管理、删除任务 |

**任务状态流转**：未开始 → 进行中 → 已完成（系统按计划日期自动标记「已延期」）

---

## 二、登录与入口

1. 门户登录后点击「**项目追踪**」卡片
2. 左侧菜单（共 11 项）：项目看板 / 任务看板 / 任务列表 / 项目列表 / **里程碑 / 风险管理 / 变更管理 / 甘特图 / 关系图谱** / 项目模板（仅 PM/ADMIN）/ 状态机管理（仅 ADMIN）

---

## 三、任务看板

- 顶部统计卡：项目数 / 总任务 / 已完成 / 进行中 / 已延期
- **OA 摘要卡**：看板顶部三张卡片（里程碑未达成 / 风险未解决 / 变更待审批），点击直达对应管理页——不用逐页翻
- 任务按「未开始 / 进行中 / 已完成 / 已延期」四列展示，卡片带进度条与项目标签；**已延期卡片红色边框**强调
- **我的任务**：点右上「我的任务」只看本人名下任务，再点取消
- **新建任务**：点「新建任务」弹窗填写（自动带入当前选中项目）：
  - 标题（必填）、所属项目、类别、优先级、**责任人**、计划开始/结束日期、描述
  - 前置依赖（其他任务，下拉选择）——被依赖任务未完成时会有阻塞提示
- **自动刷新**：看板每 30 秒静默轮询，他人流转了任务你的看板会自动更新（无变化不打扰拖拽操作；切到别的页面自动暂停）
- **筛选记忆**：项目/类别/优先级/责任人筛选会自动记住（浏览器本机），下次进入看板自动恢复；链接带筛选参数时以链接为准

---

## 四、任务列表

- 跨项目筛选（项目 + 状态）+「查询」；已延期行红色高亮
- **只看我的**：只显示本人名下任务
- **行内快捷流转**：未开始任务显示「开始」、进行中显示「完成」，点按钮直接流转，不用进详情
- **分页**：每页 50 条，底部翻页
- **导出 CSV**：导出当前筛选结果（Excel 直接打开不乱码）

---

## 五、任务详情

点任务标题进入，结构为「主信息卡 + 5 个页签」：

| 区域 | 内容与操作 |
|---|---|
| **主信息卡** | 状态（含进度条）、项目、类别、优先级、责任人、计划/实际日期、描述、前置依赖；**编辑**、**子任务**、**删除任务**（按权限）按钮在此；另有**快捷流转条**——按当前状态直接点「▶ 开始 / ✔ 完成 / ↩ 退回 / ↩ 重新打开」，不用进编辑弹窗 |
| **子任务** | 创建子任务；勾选三态流转（未开始/进行中/完成），完成度自动联动主任务进度；每行显示**指派人与计划日期**；**拖「⋮⋮」调整执行顺序**（自动保存，仅 ADMIN/PM/任务责任人/创建人可排） |
| **评论** | 任务讨论留言；输入 **@** 弹出成员候选自动补全，被提及的人会**收到站内通知**，评论里 @名字 高亮显示 |
| **附件** | 上传/查看任务相关文件；**图片类自动显示缩略图**，点开看大图 |
| **关联** | 关联样品 / 治具 / 其他任务（下拉选择，无需手填编号） |
| **日志** | 任务全量操作留痕 |

> 页签名称旁带**计数徽章**（子任务/评论/附件数量一眼可见）；前置依赖与关联对象都用下拉选择器；依赖关系带环检测，非法依赖保存时会被拦截。
> 打开详情先显示**骨架屏**再填充数据（与样品/治具详情一致的加载体验）；编辑弹窗里改过字段后点「取消」或直接切别的任务，会先弹确认防止修改丢失。

## 六、里程碑（PM/ADMIN 管理，全员可看）

1. 菜单「**里程碑**」→ 顶部下拉**选择项目**
2. 点「**新建里程碑**」：名称*、目标日期、排序（小在前）、描述
3. 列表卡片显示：目标日期 / 达成状态 / **超期红字提醒**（目标日已过仍未达成）
4. 管理员或 PM 可执行：「**达成**」（记录实际日期，延期则标注）、「编辑」、「删除」；达成后卡片转绿色 ✔

> 里程碑会同步出现在「甘特图」（◆ 菱形标记）与项目进度概览中。

---

## 七、风险管理

1. 菜单「**风险管理**」→ 选择项目 →「**识别风险**」
2. 填写：风险名称*、类型（进度/质量/资源/技术/其他）、**严重度**（高/中/低）、**概率**（高/中/低）、影响说明
3. 列表卡片：严重度与概率按颜色分级（高=红 / 中=橙 / 低=绿），一眼看出最需要关注的风险
4. 流转：识别 →「**解决**」（记录解决人与日期）→ 已解决；「编辑」「删除」仅 PM/ADMIN

> 权限：任何项目成员都可**识别**风险；处置动作归 PM/ADMIN。

---

## 八、变更管理

1. 菜单「**变更管理**」→ 选择项目 →「**发起变更**」
2. 填写：变更类型（**范围 / 时间 / 资源 / 预算**）、变更前→变更后、原因、说明
3. 审批：**PM/ADMIN** 点「批准 / 驳回」；**申请人不能审批自己发起的变更**（按钮不出现）
4. 状态：待审批（橙）→ 已批准（绿）/ 已驳回（红）；待审批状态申请人可「编辑 / 删除」
5. **生效规则**：预算类变更批准后自动写入项目预算；时间类批准仅留痕，任务日期需自行调整（保守设计）

---

## 九、甘特图

1. 菜单「**甘特图**」→ 选择项目（支持 `#/gantt?project=N` 直达）
2. 图中元素：
   - **任务条**：按状态着色（灰=未开始 / 蓝=进行中 / 绿=已完成 / 红=阻塞），今天线标红
   - **里程碑 ◆**：棕色菱形，空心=已延期
   - **依赖箭头**：前置任务终点 → 后续任务起点，一眼看出执行顺序
3. 图例在顶部，横向滚动查看长周期项目

> 任务条按计划结束日锚定；未填日期的任务不显示。

---

## 十、关系图谱

1. 菜单「**关系图谱**」：全部项目按力导向布局成图，节点=项目（状态色 + 完成率环）
2. **标注关系**：点按钮选两个项目 + 关系类型——依赖（红）/ 衍生（紫）/ 共享机型（灰虚线，系统自动推导）/ 替代（橙）/ 关联（青）/ 同一客户（绿）/ 自定义
3. 交互：**拖拽**节点调整布局、**点击**节点出摘要卡、**点击**连线看关系说明、顶部勾选按类型**过滤**
4. **聚簇模式**（图谱放大后看不清时的好帮手）：
   - 「**状态簇**」：进行中/已完成项目各聚成一个大节点（显示项目数与平均完成率）
   - 「**族谱簇**」：按关系边（含共享机型自动推导）连通的项目聚成一族，族名取共享机型编号
   - 大节点**点击下钻**展开成员，成员图内点「收起」回到聚合视图
   - 聚簇模式下点击项目节点会**高亮其直连邻居**（其余淡化），再点一次取消
5. 「**导出 PNG**」保存当前图谱（聚簇/展开状态都会被导出；汇报/评审直接贴图）

## 十一、项目模板（PM/ADMIN）

1. 菜单「**项目模板**」→「**新建模板**」：模板名称* + 说明 + **任务清单**（标题/类别/优先级/偏移天数=距项目启动日）+ **里程碑清单**（名称/目标偏移天数）
2. 「**从模板创建项目**」：选模板 → 填项目名与启动日 → 系统按偏移天数自动生成全部任务与里程碑计划日期
3. 卡片显示模板内任务数 / 里程碑数 / **已实例化次数**；「编辑」调整清单，「停用」下架模板

> 适合同类项目（如设备导入、质量改进）复用标准任务组合，免每次手工建任务。

---

## 十二、状态机管理（仅 ADMIN）

1. 菜单「**状态机管理**」：表单化配置，无需改代码
2. **状态配置**：改每个状态的显示标签与颜色（如把「未开始」改叫「待启动」）
3. **流转配置**：每条 `源 → 目标` 流转可改**允许角色**（逗号分隔，如 `ADMIN,ASSIGNEE`）与按钮标签
4. 「保存配置」后全系统生效；校验不通过（缺标签/缺角色）会逐项提示

---

## 十三、站内通知（项目子系统）

- 右上角**铃铛**显示未读数（每分钟自动刷新），点开通知面板
- **什么时候会收到通知**：
  - 任务**指派给你**（新建带责任人 / 编辑改派 / 批量改派）
  - 你创建的任务被**完成或退回**（操作人非本人时）
  - 评论里 **@提及你**（输入 @ 从候选列表选人，直接打字不会被识别）
- 点击通知直达任务详情并自动标已读；「**全部已读**」一键清零

---

## 十四、我的待办联动

工作台「我的待办」会汇总**指派给你的**未完成任务与子任务（含延期标记），点击直达任务详情处理——不需要挨个项目翻看板。

---

## 十五、常见提示

- **删除失败 409**：项目下还有任务，先处理/转移任务
- **依赖阻塞**：前置任务未完成时，任务可保存但看板会提示依赖关系，建议按依赖顺序执行
- **看不到别人的任务**：任务按责任人归属，「我的任务/只看我的」开关控制过滤，全部任务请关闭过滤
- **看板筛选被"记住"了**：筛选记忆存在本机浏览器，换设备/清缓存即恢复默认；不想记忆可清浏览器站点数据
- **变更单没有批准/驳回按钮**：要么不是 PM/ADMIN，要么这是你自己发起的变更（申请人不能自审）
- **甘特图看不到某任务**：该任务没填计划日期；里程碑空心 ◆ 表示已延期
