# 管制系统操作说明（使用人员版）

> 适用对象：不良品管制全流程操作人员（各部门申请/会签人、品保、保管、生技、管理员）
> 版本：v2.x | 更新：2026-09-04

---

## 一、这套系统管什么

不良品管制全流程数字化：从发现不良 → 申请管制 → 会签把关 → 贴标入仓 → 委托检验（NCR）→ 决定处理方式 → 重工执行 → 数量闭环出货。电子表单与纸质《不良品委托检验单》（GYS-Q2-008_01）栏位一致，可直接打印存档。

**状态流转**：
申请草稿 → 管制会签中 → 已贴标签 → 已入管制仓 → 委托单已开 → 处理会签中 → 重工工单已开 → 重工执行中 → 已报工 → 已入库 → 已出货
（任意中间态管理员可作废；会签任一字位退回会整单回退——退回在「去会签」弹窗里选，重新提交后该闸口全部重签）

**每一步谁来做**：

| 步骤 | 操作 | 谁执行 |
|---|---|---|
| 1 | 新建申请（草稿） | 各部门（本部门起草） |
| 2 | 提交会签 | **申请部门**（QA/保管/生技角色） |
| 3 | 闸口①会签（5 个字位） | 品保、研发、生管、制造部、仓库 **各自签自己的字位** |
| 4 | 闸口①通过/贴标 | 品保 QA |
| 5 | 入管制仓（登记储位） | 仓库口（资材部保管） |
| 6 | 开不良品委托单 | 品保 QA |
| 7 | 发起处理方式会签 | 品保 QA |
| 8 | 闸口②会签（2 个字位） | 品保、研发 各自字位 |
| 9 | 生产确认开工（填重工工单号） | 生技 ME |
| 10 | **追加报工（重工结果录入）** | 生产口保管（制造/生管/资材部）、生技 |
| 11 | 报工确认 → 入库 → 出货 | 仓库口保管、生技 |

## 二、登录与入口

1. 门户登录后点击「**管制流程管理**」卡片
2. 左侧菜单：管制看板 / 我的待办 / 管制单列表 / 不良品委托单 / 新建管制申请 / 管制标签打印 / 操作日志(管理员)

---

## 三、新建申请（各部门）

1. 点「新建管制申请」
2. 填写：**料号**、**品名**、**数量**、**不良类型**（外观/功能/尺寸/性能/包装/其它）、**管制/不良原因**（必填）；销货单号、机型、喷码日期、客户选填
3. 提交后生成管制单号 `CTL-日期-流水`，状态「申请草稿」
4. **提交会签由申请部门执行**（谁申请谁提交）——提交后进入会签

---

## 四、会签（重点：并行 + 按部门）

- **并行**：闸口① 5 个字位（品保→研发→生管→制造部→仓库）不分先后，可以同时签，不用等上一个人
- **按部门**：**你只能签自己部门的字位**——制造部的人签「制造部」步，不能替生管/仓库签（系统会拒绝并提示该步待哪个部门）
- **入口**：打开单据详情，主卡「操作」区最左侧的「**去会签（闸口①/②）**」按钮（只有轮到你的字位才出现）；「会签闸口」页签可查看全部字位的签核状态
- 签字时选择 **同意 / 退回**，退回必须填意见；任一字位退回 → 整单退回起草人重新修改
- **退回是会签的一部分**（2026-09-04 闭环）：退回只能在上面的「去会签」弹窗里选——操作区没有独立的「会签退回」按钮；退回人、退回意见会记录在「会签闸口」页签该字位上
- **退回后重新提交 = 全部重签**：起草人改完点「提交会签」，上轮所有签字（含同意与退回）清空，5 个字位从头再签；上轮结论可在「操作日志」追溯
- 管理员可代签任意字位、可强制跳过

**在哪里看到轮到我签**：工作台「我的待办」/ 管制看板待办区会显示「待我会签」；详情页出现「去会签」按钮。

---

## 五、贴标与入仓

1. 5 个字位全部同意后，**品保**点「闸口①会签通过/贴标」→ 系统生成管制标签号（LB-单号）
2. 到「管制标签打印」页打印标签贴于实物
3. **资材部保管**在详情点「入管制仓」，填写**管制仓储位**（必填）

---

## 六、不良品委托检验单（NCR）

### 6.1 开单（品保）

1. 已入管制仓的单据，品保点「开不良品委托单」
2. 弹窗**自动预填委托单号**（NCR-管制单号-序号，可手工修改），选择**检验部门**和**处理部门**后提交
3. 同一管制单可开**多张**委托单（序号自动递增）

### 6.2 电子表单与打印

- 详情页「电子表单」页签 = 单张《不良品委托检验单》，点「打印」直接出单
- 表单内容：基本信息 → 不良原因分析 → 解决方案 → 重工/全检标准 → **处理结果**（数量为全部报工批次累计）→ 签署栏
- 表单头部显示**委托单号**，编号可追溯

---

## 七、处理方式与重工执行（重工结果在这里录入）

1. **发起处理方式会签**（品保）：填写**重工SOP**（必填）+ 现场指导/其他标准文件（至少填一项）→ 进入闸口②
2. **闸口②会签**（品保+研发各自字位）：通过时填写**处理方式结论**（自动上电子表单）
3. **生产确认开工**（生技）：填写**重工工单号** → 状态「重工执行中」
4. **追加报工**（生产口保管/生技）：录入**良品数、不良数、报废数、报废原因、批次号、包装称重、确认人、数量是否一致**
   - 可**多次分批报工**：每报一次，主单数量自动累加、结余自动重算
   - 每次报工在详情「报工」页签留一条记录
5. **报工确认**（点「报工」按钮）：系统校验——必须**已有报工记录**且**结余清零**（数量=良+不良+报废），否则拦截并提示
6. **入库**（仓库口/生技）：纯确认动作
7. **出货**（仓库口/生技）：出货前系统复核**结余必须=0**，确保重工结果数量闭环

---

## 八、详情页导览

- **主卡**：单号+状态、字段卡（基本信息/管制信息/执行结果/备注）、11 步进度条、5 阶段卡
- **操作区**（轮到谁才显示谁的按钮）：`去会签（闸口①/②）` → `追加报工` → 流转按钮 → `作废`（仅管理员）；退回在「去会签」弹窗内选，不是独立按钮
- **明细页签**：会签闸口（签核状态）/ 不良品委托单（历次 NCR）/ 报工（报工历史表）/ 操作日志 / 电子表单

---

## 九、看板、列表与超期

- **管制看板**：状态分布 + 待办区（待我流转/待我签核）
- **管制单列表**：状态/申请部门/不良类型/关键词筛选；**超期单**（48 小时无动作，管理员可调阈值）自动高亮；「已贴标」筛选用可打印清单
- **不良品委托单页**：跨单 NCR 清单，支持筛选与 CSV 导出
- **作废**：仅管理员，任意中间态可作废（需填原因，全量留痕）

## 十、常见提示

| 提示 | 含义与处理 |
|---|---|
| 会签按部门执行：该步待 X 签核 | 你想签别人部门的字位了——各签各的，不能代签 |
| 该操作由仓库口（资材部）执行，您所在部门无权操作 | 仓口动作按部门硬校验（2026-09-04 下沉）：入仓=资材部、报工=生产口、入库/出货=资材/生管；兼任生技/品保角色的账号不受限 |
| 请先追加报工记录 | 点了「报工」确认但还没录过数量——先「追加报工」 |
| 结余未清零（余 N） | 报工数量加起来 ≠ 申请数量——继续报工补齐或核对数量 |
| 该节点会签已完成 | 字位都签完了，无需再签 |
| 该管制单刚被他人操作 | 有人和你同时操作，刷新页面重试即可 |
| 当前节点待 X 会签 | 还没轮到你/你部门，等待即可 |

> **多角色账号**（2026-09-04）：管理员可在用户管理为一个账号配置多个角色（如 QA+CUSTODY），待办与可执行动作取并集；但会签字位仍按"角色+部门"匹配，仓口动作对纯保管角色仍按部门门槛校验。
