# 样品系统操作说明（使用人员版）

> 适用对象：样品管理各环节操作人员（研发/品保/保管/生技/管理员）
> 版本：v2.x | 更新：2026-08-07

---

## 一、你能做什么

| 角色 | 部门 | 主要操作 |
|---|---|---|
| 研发 RD | 研发部 | 新建样品、打印标签、确认制作完成、创建替代品 |
| 品保 QA | 品保文管中心 | 确认发行（三步向导）、复检、审核退回 |
| 保管 CUSTODY | 制造部 / FQC | 接收保管、登记储位、申请退回 |
| 生技 ME | 生技部 | 同保管：接收保管、登记储位、申请退回 |
| 管理员 ADMIN | 系统 | 用户管理、全局查看 |

> 生技部(ME)属于保管单位，**不可建样和确认制作**。

**样品状态流转**：新建待制作 → 制作完成 → 已发行 → 保管中 ⇄ 退回审核中 → 已作废

---

## 二、登录与入口

1. 打开系统首页（门户），页面显示**登录框**，输入**账号**和**密码**，点击「**登 录**」
2. 登录成功后出现各子系统卡片，点击「**样品管理**」进入样品系统
3. 门户顶部显示当前用户和「退出」链接，点「退出」可退出登录
4. 也可直接访问样品系统入口页地址（登录页），输入账号密码后进入
5. 左侧菜单：看板 / 新建样品 / 扫码台 / 样品列表 / 操作日志

---

## 三、研发（RD）操作

### 3.1 新建样品

1. 点击菜单「新建样品+打印码」
2. 填写**基础信息**（必填）：
   - **样品名称** — 如「1225震动样」
   - **规格/型号** — 下拉选择机型（需先在机型列表添加），选择后自动填入**机型编码**
   - **提供处** — 客供(C) / 元山(T) / 塔岗(G)
   - **组别** — 扇叶组 / 马达组 / 成品组 / 品保部 / SMT / 供应商
   - **备注** — 自由填写
3. **限度样品信息**（选填）：
   - **样品类型** — OK样品 / NG样品
   - **限度项目** — 下拉选择（如成品震动、外观等）
   - **版次** — 首发自动 `01`，也可手动输入（01~99）
   - **标准范围** — 限度判定标准，如「震动≤0.5mm」
4. 点击「创建样品并生成条码」
5. 系统自动生成 **13 位样品编号**（如 `G-YD9015-Q-001-01`：提供处-机型-组别-流水号-版次），**生成后固定，不随版次变化**
6. 弹出标签打印页，**打印标签贴于样品实物上**

### 3.2 补打标签

标签遗失或打印失败时：样品列表 → 找到该样品 → 点「**打印**」补打；点「**下载 QR**」可下载二维码图片。

### 3.3 确认制作完成

1. 进入「扫码台」，扫描或输入样品编号
2. 上传**制作照片**（必填），可填备注
3. 点击「确认制作完成」→ 状态变为「制作完成」

### 3.4 创建替代品（被指派退回重做时）

1. 扫描「退回审核中」且已指派给你的样品
2. 点击「创建替代品」
3. 系统自动复制原样品信息（名称/规格/机型/组别/标示卡等），生成新编号
4. 新样品按正常流程制作 → 发行 → 分发；原样品自动变更为「已作废」

## 四、品保（QA）操作

### 4.1 确认发行（三步向导）

**Step 1 — 设置复检周期**
- 默认 **365 天（1 年）**，可手动调整，实时预览下次复检日期
- 点「下一步：填写标示卡」

**Step 2 — 标示卡审查**
- 全部字段平铺展示，标记 `✓ RD已填` / `✗ 必填`
- **必填**：样品类型（OK/NG）、限度项目
- **自动带入**研发已填的：提供处、标准范围、测试数据；**版次**发行时自动设为 `01`（重新发行自动 +1）
- 点「下一步：确认发行」（类型和项目未填则无法继续）

**Step 3 — 确认发行**
- 核对摘要（复检周期、下次复检日期、类型、项目）
- 点「确认正式发行」→ 状态变为「已发行」，自动弹出标示卡打印

### 4.2 复检

样品到期后扫描其二维码：
1. 上传**复检照片**（必填），可填备注
2. 复检周期默认沿用上次，可修改
3. 「标示卡更新」为选填（可改版次/测试数据，不填保留原值）
4. 点「确认复检完成」→ 下次复检日期自动顺延

### 4.3 审核退回（4 个分支）

扫描「退回审核中」样品，可选：

| 分支 | 操作 | 结果 |
|---|---|---|
| 重新发行 | 进入三步向导，版次自动+1 | 恢复「已发行」 |
| 退回研发重做 | 下拉指派研发人员，填作废原因 | 保持退回审核中，研发收到待办 |
| 直接作废 | 填写作废原因（必填） | 状态「已作废」 |
| 拒绝退回 | 填写拒绝理由（必填） | 恢复「保管中」 |

## 五、保管 / 生技操作

### 5.1 接收保管

1. 扫描「已发行」样品二维码
2. 填写**保管储位**（必填），如「A区-3架-2层」
3. 点击「确认接收保管」→ 状态「保管中」，记录储位和保管部门

### 5.2 申请退回

1. 扫描「保管中」样品二维码
2. 点「申请退回」，填写**退回原因**（必填）
3. 提交后状态「退回审核中」，等待品保审核

## 六、扫码台使用

| 方式 | 说明 |
|---|---|
| **扫码枪**（推荐） | 对准二维码自动填充，适合批量作业 |
| **手动输入** | 输入 13 位编号（如 `G-YD9015-Q-001-01`）或兼容旧编号 `SM-XXXXXX`，回车 |
| **摄像头扫码** | 手机端（需 HTTPS），点「开启摄像头」 |

**连续扫码**：勾选后每次操作完自动清空并聚焦，适合扫码枪连续作业；连续模式下发行后的标示卡进入打印队列，可「打印全部」或「清空」。

## 七、样品列表与查看

### 7.1 筛选

支持按**搜索**（编号/名称/规格）、**状态**、**部门**、**类型**（OK/NG）、**限度项目**、**提供处**、**机型**筛选与排序；快捷筛选：待处理 / 逾期 / 近 7 天。

### 7.2 复检状态列

| 徽章 | 含义 |
|---|---|
| 正常 | 距下次复检超过 7 天 |
| 近7天到期 | 未来 7 天内需复检（黄色） |
| 逾期N天 | 已超期 N 天（红色） |
| — | 未设置复检周期 |

### 7.3 详情弹窗

- **信息**：基础信息、流转进度、保管信息、操作日志
- **标示卡**：样品类型、限度项目、提供处、版次、样品数值（测试数据）、标准范围、签署人；已发行后的标示卡自动锁定，仅可查看打印
- **全量日志 / 大图**：完整操作记录与照片

### 7.4 其他

- 点「**导出 CSV**」可下载当前筛选结果（Excel/WPS 直接打开）
- **取消样品**：仅「待制作/制作完成」状态可取消，仅管理员或创建者本人

## 八、标签尺寸设置

标签打印页顶部可选尺寸，标示卡自动等比缩放：

| 尺寸 | 标签 | 标示卡 |
|---|---|---|
| 小号 | 37×18mm | 21×12mm |
| 中标（默认） | 52×25mm | 29×17mm |
| 大号 | 60×40mm | 32×35mm |
| 自定义 | 30~150mm 可调 | 自动等比缩放 |

## 九、常见提示

- **无权操作**：出现「你的角色无法推进该样品」时，说明该状态不属于你的操作环节，请按流程顺序操作或联系对应部门
- **标示卡锁定**：样品已发行后标示卡不可修改，需修正请联系管理员
- **复检逾期**：首页概览和看板会列出逾期样品，请品保及时安排复检

## 十一、各部门硬件配置要求

> 系统服务器及网络设备由 IT 统一部署，本表仅列各部门操作岗位需自行配备的**终端硬件**。

| 硬件 | 用途 | 研发(RD) | 品保(QA) | 保管/生技(CUSTODY/ME) | 说明 |
|---|---|---|---|---|---|
| 电脑 | 登录系统、列表查询、打印 | 必配 | 必配 | 必配 | Windows 10 及以上，Chrome/Edge 浏览器，屏幕建议 1080p |
| 扫码枪 | 扫码台扫描样品二维码 | 必配 | 必配 | 必配 | USB 或无线，**模拟键盘输入**模式，即插即用免驱动 |
| 标签打印机 | 打印样品标签（建样 / 补打） | 必配 | 选配 | 选配 | 热敏标签打印机 + 标签纸（见下方尺寸说明） |
| 普通打印机 | 打印标示卡 | 选配 | 必配 | 选配 | A4 激光 / 喷墨即可 |
| 手机（带摄像头） | 无扫码枪时备选扫码 | 选配 | 选配 | 选配 | 需 HTTPS 环境，扫码台点「开启摄像头」 |

**选购与使用注意**：

- **扫码枪**：选择支持「模拟键盘输入」的型号（扫描后自动输入编号并回车），无需安装驱动；连续扫码模式需勾选「连续扫码」开关
- **标签纸**：系统支持 3 档尺寸——小号 37×18mm / 中标 52×25mm（默认）/ 大号 60×40mm，另支持 30~150mm 自定义；现场统一采购与系统尺寸一致的标签纸即可
- **标示卡**：随标签纸同一规格打印，也可用普通 A4 打印机走纸质流程
- **浏览器**：推荐 Chrome / Edge 最新版，勿用 IE 兼容模式
