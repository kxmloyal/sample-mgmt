# 门户首页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为制造品质管理系统新增门户首页（portal.html），登录后展示子系统入口，样品管理可进入，治具管理灰色占位。

**Architecture:** 新建独立 `public/portal.html`（纯 HTML+CSS+内联 JS），登录成功后从 index.html 跳转至 portal.html。同一域名下 cookie 自动共享，portal.html 通过 `/api/me` 验证登录态。

**Tech Stack:** 原生 HTML/CSS/JS，复用项目现有 CSS 变量（:root），零依赖。
