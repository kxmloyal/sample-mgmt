# 前端使用指南（混合方案）— 设计文档

> 日期：2026-07-25 | 状态：已确认

## 一、目标

在系统前端界面中嵌入完整的使用指南，采用混合方案（浮动按钮 + 搜索 + 上下文提示），帮助内容按功能模块组织，纯前端 JS 常量实现。

## 二、架构

```
public/
├── js/
│   ├── help-data.js    # 帮助内容数据（按模块组织，10 个模块）
│   └── help.js         # 浮动按钮 + 搜索面板 + 上下文提示逻辑
├── css/
│   └── app.css         # 新增帮助组件样式（~40 行）
└── index.html          # 引用新 JS + 浮动按钮容器（+3 行）
```

纯前端实现，无后端 API 改动，无数据库改动。

## 三、数据结构

帮助内容按功能模块组织，每个模块包含角色标签、关键词、摘要、分节内容：

```js
var HELP_DATA = [
  {
    id: 'create',
    title: '建样（新建样品）',
    roles: ['RD'],
    tags: ['建样','新建','打印','标签','QR码','限度样品'],
    summary: '填写样品信息 → 生成编号 → 打印标签贴样',
    sections: [
      { h: '操作步骤', body: '1. 点击「新建样品+打印码」\n2. 填写基础信息...' },
      { h: '限度样品字段', body: '样品类型/限度项目/来源/版次...' },
      { h: '注意事项', body: '编号自动生成，不可修改...' }
    ]
  },
  // ... 其余 9 个模块
];
```

### 模块清单（10 个）

| ID | 模块标题 | 适用角色 |
|---|---|---|
| login | 登录与账号 | ALL（不含具体账号密码） |
| create | 建样（新建样品） | RD |
| scan | 扫码台（三方共用） | RD, QA, CUSTODY, ME |
| release | 品保发行向导 | QA |
| inspect | 品保复检 | QA |
| return | 退回与作废 | CUSTODY, QA, RD |
| print | 打印（标签+标示卡） | RD, QA |
| list | 样品列表与筛选 | ALL |
| board | 生命周期看板 | QA, CUSTODY, ME |
| users | 用户管理 | ADMIN |

## 四、UI 组件

### 4.1 浮动按钮

- 位置：固定在右下角（`position:fixed; bottom:24px; right:24px`）
- 样式：蓝色圆形按钮（48×48px），白色「?」图标
- 行为：点击展开搜索面板，再次点击或点击遮罩关闭
- 可见范围：登录后所有页面
- z-index：999（确保在弹窗之上）

### 4.2 搜索面板

- 展开方式：居中弹窗，max-width 600px，最大高度 80vh 可滚动
- 结构：
  ```
  ┌──────────────────────────────────┐
  │ 🔍 [搜索关键词...              ] │  ← 搜索框（实时筛选）
  ├──────────────────────────────────┤
  │ 📋 建样（新建样品）    [研发]    │  ← 模块卡片
  │    填写样品信息 → 生成编号...    │
  │    [展开详情 ▼]                  │
  ├──────────────────────────────────┤
  │ 📱 扫码台             [研发 品保] │
  │    三方扫码驱动状态流转...       │
  │    [展开详情 ▼]                  │
  └──────────────────────────────────┘
  ```
- 搜索逻辑：匹配 title / tags / summary / sections.body，不区分大小写
- 角色过滤：仅显示当前用户角色相关的模块（ALL = 全部角色）
- 模块卡片：默认折叠显示 summary，点击展开 sections 详情
- 定位跳转：上下文提示条点「了解更多」时，通过 `openHelp(id)` 函数直接打开面板并展开对应模块（不走 URL 参数，因项目使用 hash 路由）

### 4.3 上下文提示条

- 位置：功能页面 topbar 下方（`#view` 区域顶部）
- 内容：当前页面的简短说明 + 右侧「了解更多 →」链接
- 可关闭：点击 ✕ 关闭，本次会话不再显示（sessionStorage 记录）
- 映射关系：

| 页面 hash | 提示文本 | 对应帮助模块 |
|---|---|---|
| #/dashboard | 首页概览：查看统计数据和待办事项 | — |
| #/samples | 样品列表：支持多维度筛选和详情查看 | list |
| #/new | 新建样品：填写信息后自动生成编号和标签 | create |
| #/scan | 扫码台：扫描样品二维码驱动状态流转 | scan |
| #/board | 生命周期看板：查看复检逾期和即将到期样品 | board |
| #/logs | 操作日志：系统全局操作记录 | — |
| #/users | 用户管理：管理账号和角色 | users |

## 五、交互流程

```
用户登录
  ↓
右下角显示浮动「?」按钮 + 各页面顶部显示上下文提示条
  ↓
方式1: 点击「?」→ 搜索面板 → 输入关键词/浏览分类 → 点击模块展开详情
方式2: 进入功能页面 → 顶部提示条 → 点「了解更多」→ openHelp(id) 打开面板定位到对应模块
```

## 七、约束与规范

- help-data.js 为常量数据文件（豁免上限 800 行），预估 ~200 行
- help.js 为独立脚本（上限 300 行），预估 ~150 行
- app.css 当前 121 行，新增 ~40 行后 ~161 行（上限 200 行，80.5%）
- 顶层函数 ≤10/文件
- 遵循项目现有代码风格：函数声明、camelCase、单行 CSS

## 八、不涉及

- 后端 API（纯前端实现）
- 数据库改动
- 现有功能逻辑改动
- AGENTS.md / CLAUDE.md 修改
- 帮助内容中**不显示具体登录账号密码**，仅说明登录操作步骤

## 九、未来扩展

- 如需动态管理帮助内容，可迁移到后端 API + JSON 方案
- 如需支持图片/视频教程，可在 sections 中扩展 type 字段
- 如需支持多语言，可抽取为 i18n 数据结构
