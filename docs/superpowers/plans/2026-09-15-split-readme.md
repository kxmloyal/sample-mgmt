## 3. 拆分方案

**方案 A（推荐）**：`## API 一览`（4,457 字符）外迁 `docs/api.md`，README 原位留 3~5 行指针。
- 依据：AGENTS.md §13 已把 `docs/api.md` 列为接口文档的规范位置，非新造载体。
- 效果：19,714 − ≈4,340 = **≈15,374 字符（76.9%）**，一步脱离 90% 告警区。

**方案 B（方案 A 之后按需）**：再把 `## 目录`（2,032 字符）外迁或精简为顶层骨架 → 约 13,400 字符（67.0%）。

**顺带清理（低风险）**：`### 演示账号`（L224，projects 子系统的 `pm01`）与 `## 演示账号`（L302，全局 8 账号表）**标题同名易混淆**，前者改名为 `### 项目追踪演示账号` 并与后者互链。
